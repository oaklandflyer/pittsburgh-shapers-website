EVENTS MANAGER

Events now come straight from the Global Shapers PGH Google Calendar. Add an event to the calendar and it shows up on the site within the hour; once it's over, it disappears on its own. You only need this page to add a photo or button to an event, hide one, or post something that isn't on the calendar.

1 Connect to the website
How do I get a token? (one time, ~2 minutes)
  1. Go to github.com/settings/personal-access-tokens/new (Fine-grained tokens).
  2. Resource owner: oaklandflyer. Repository access: Only select repositories → pittsburgh-shapers-website.
  3. Permissions → Repository permissions → Contents → Read and write. Also set Actions → Read and write if you want the “Sync now” button to work.
  4. Generate the token (starts with github_pat_) and paste it above. It's saved only in this browser.
